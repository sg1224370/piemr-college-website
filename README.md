# PIEMR Indore – Responsive College Website

A modern and responsive college website developed for **Prestige Institute of Engineering Management & Research (PIEMR), Indore, Madhya Pradesh**.

The project aims to provide an attractive and user-friendly online platform where students, visitors, and prospective applicants can explore institutional information, academic programs, admissions, placements, campus facilities, and research activities.

## About the Project

This website is designed with a professional interface featuring a navy-blue and gold colour scheme. It provides a structured layout with multiple sections to make institutional information easily accessible.

The website is developed using HTML5, CSS3, and JavaScript without any frontend frameworks.

## Features

- **Welcome Screen:** Interactive introductory screen.
- **Responsive Navigation:** Easy navigation with a mobile-friendly hamburger menu.
- **Home Section:** Attractive landing page with campus imagery.
- **About PIEMR:** Information about the institution.
- **Institute Highlights:** Displays institutional milestones and academic credentials.
- **Academic Programs:** Showcases featured engineering disciplines.
- **Program Details:** Interactive modal windows displaying program information.
- **Admissions:** Admission information and enquiry form interface.
- **Placements:** Dedicated section for career and placement information.
- **Campus Life:** Highlights campus activities and facilities.
- **Research:** Dedicated research and innovation section.
- **Contact:** Contact information and enquiry interface.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.

## How to Run the Project

1. Download or clone this repository.
2. Extract the project folder if downloaded as a ZIP file.
3. Open the project folder in Visual Studio Code.
4. Open `index.html`.
5. Run the website using Live Server or directly through your browser.
